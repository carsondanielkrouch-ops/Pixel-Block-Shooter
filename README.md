# Pixel Block Shooter

A starter project for a pixel-style block shooter game.

## Project structure

- `src/` — game source code
- `assets/` — sprites, sounds, and other game assets
- `tests/` — automated tests
- `docs/` — design notes and documentation

The engine and programming language have not been selected yet.

## Website

The project includes a Pages-ready `index.html` landing page.
